# 评鉴浮窗 · 三国杀OL 许劭「评鉴」提示器

按热键截取游戏窗口画面 → 本地 OCR 识别 6×6 棋盘 → 浮窗按原棋盘排布显示所有可连成的战功，以及对应技能/武将/时机。

> **重要：本工具是纯截图识别，不注入游戏进程**
> 不读写游戏内存、不 hook 客户端、不发送键鼠输入、不修改任何游戏文件——只对屏幕做一次截图然后在本地做识别，所以**不存在注入类外挂的封号风险**。

> **重要：OCR 必然有识别误差，请自己核对**
> 作者实测：**在砸蛋之前识别，错误率非常低，一整晚通常只有 1~2 次错误**。
> 鸡蛋遮挡棋盘、游戏窗口缩放/换分辨率、界面高亮字变化时更容易认错；识别结果里如果某格有偏差会标出「校正 X→Y」，拿不准就按 `Ctrl+F7` 重新校准棋盘框再识别一次。

---

## 功能

- 一键抓屏识别，浮窗**按原始 6×6 排布**显示棋盘，命中的战功用彩色框标出；
- 列出每条战功 → 技能 · 武将 · 时机，`★` 表示本次更新新增的条目；
- 鸡蛋格自动识别并按通配处理；
- 候选字级整词求解：单格认错时，只要正确字在候选里，整条战功仍能还原并标出校正；
- 只读屏幕，不注入、不改文件。

## 环境要求

- Windows 10 / 11（64 位）
- Python 3.9+
- `pip install pillow numpy`

> 不想装 Python 的，可以用打包好的免安装 exe 版（Release 里单独提供）。

## 启动

双击 `启动评鉴浮窗.bat`（无控制台窗口；异常会写入 `pj_error.txt`）。

## 热键

| 功能 | 默认键 | 说明 |
|---|---|---|
| 抓屏识别 | **F2** | 棋盘弹出时按；可在配置里改 |
| 校准棋盘框 | Ctrl+F7 | 拖框圈住 6×6 棋盘，只需一次，会记住 |
| 显示 / 隐藏 | Ctrl+F9 | 隐藏后按 Ctrl+F9 叫回来 |
| 退出 | Ctrl+Alt+Esc | 也可点浮窗右上角 ✕，或右键 → 退出 |

热键被其它软件占用时会自动顺延到备用键，实际生效的键显示在浮窗提示与 `pj_log.txt` 里。

## 配置 `pj_config.json`（可选，自动生成）

```json
{
  "capture_key": "F2",     // F1~F12、字母(如 "f")、空格、alt+空格、ctrl+空格、tab、`
  "rect": [x, y, w, h],    // Ctrl+F7 校准后自动写入：棋盘屏幕坐标
  "pos":  [x, y]           // 浮窗位置（拖动后退出会记住）
}
```

## 使用建议

1. 进游戏，等评鉴棋盘弹出；
2. 按 **F2**，看浮窗结果；
3. **最好在对手砸蛋之前识别**（此时最准）；
4. 结果里带「校正 X→Y」的条目，建议自己扫一眼确认；
5. 识别明显不对时按 **Ctrl+F7** 重新框一次棋盘（框紧贴棋盘外沿效果最好）。

## 常见问题

- **按 F2 没反应**：看浮窗提示里实际绑定的键（可能被占用后自动顺延），或先按 Ctrl+F7 校准。
- **提示"没定位到棋盘"**：当前不在评鉴界面，或棋盘被其它窗口遮挡；游戏窗口不能最小化。
- **识别成乱码**：多半是框没贴合，重框一次；改了窗口大小/分辨率后建议重框。
- **重复双击 bat**：不会开第二个（有单实例锁）。

## 原理

1. `PrintWindow`/屏幕截图拿到游戏窗口位图；
2. 按「亮色格带」定位 6×6 棋盘，颜色感知提取每格文字（兼顾深灰字与浅蓝高亮字）；
3. 与内嵌字形图集做归一化余弦匹配，得到每格候选字；
4. 在 79 条战功词表上做「候选字级整词求解」，只认横/竖直线，鸡蛋格通配。
